# Eisenhower Matrix: WikiTrail

## DO (Urgent + Important): MVP

- Search Wikipedia and retrieve an article introduction.
- Show a numbered list of related article links and open a selected link.
- Display an ordered research trail and navigate back to a previously viewed article.

## SCHEDULE (Important + Not Urgent): V2.0+

- Create an interactive visual graph in Java Swing/Graphics2D.
- Add article notes and save/load research sessions using JSON.
- Generate contextual explanations of how each article relates to the starting topic.
- Create automatic structured summaries and recommend relevant articles.

## DELEGATE (Urgent + Not Important): Use Existing Tools

- Use Java's `HttpClient` to make HTTP requests instead of writing a network client.
- Use Gson to parse Wikipedia's JSON responses instead of building a parser.
- Use Java's `Scanner` for terminal input instead of writing custom input handling.
- Use Wikipedia's public MediaWiki API rather than scraping or hosting article content.

## DELETE (Not Urgent + Not Important): Cut

- Social accounts and sharing or collaborative editing of research trails.
- Separate iOS and Android mobile applications.
- Train a custom language model on Wikipedia content.
- Achievements, points, leaderboards, and research streaks.
- Real-time multi-user collaboration and chat.

**MVP in one sentence:** Search Wikipedia, follow article links, and retrace the full path back to the original topic in a reliable Java terminal program.
